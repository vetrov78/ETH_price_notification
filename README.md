# ETH Price Alert Bot

Telegram-бот для мониторинга цены Ethereum.

## Установка
1. Установи зависимости:
```bash
pip install -r requirements.txt
```

## Курс бразильского реала

Курс берётся из публичного API Bybit Spot: последняя цена сделки (`lastPrice`)
пары `USDTBRL`, то есть количество BRL за 1 USDT. API-ключ не нужен.
Это биржевой курс USDT/BRL, а не официальный валютный курс USD/BRL.

Для совместимости настройка порога остаётся `USD_BRL_CRITICAL_RATE`,
а команда изменения — `/set USD_BRL 5.20`.

## Доступность Hyperithm Delta Neutral Vault

Бот проверяет публичные данные Hyperithm Delta Neutral Vault в Accountable
каждые `CHECK_INTERVAL` секунд (по умолчанию — 300 секунд). Когда vault
принимает депозиты и общий объём депозитов становится меньше лимита, бот
отправляет сообщение в Telegram с доступной вместимостью и ссылкой на vault.
При запуске с уже доступным местом сообщение также отправляется. Для проверки
используются текущая вместимость и объём депозитов из публичного API; одного
флага `can_deposit` недостаточно, так как он сам по себе не отражает превышение
лимита.
